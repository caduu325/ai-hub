# AI HUB

Aplicativo único para conversar com múltiplas IAs usando um Router automático e memória central.

## Princípios
- Um único projeto principal.
- Automático por padrão; escolha manual disponível.
- Memória independente do provedor.
- Provedores desacoplados do frontend.
- Chaves somente no servidor.

## Estado inicial
Interface base e motor inicial de classificação/roteamento. Integrações reais com modelos e banco entram nas próximas etapas.
